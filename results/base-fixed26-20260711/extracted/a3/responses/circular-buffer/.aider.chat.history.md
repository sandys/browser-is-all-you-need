#### # Instructions  
####   
#### A circular buffer, cyclic buffer or ring buffer is a data structure that uses a single, fixed-size buffer as if it were connected end-to-end.  
####   
#### A circular buffer first starts empty and of some predefined length.  
#### For example, this is a 7-element buffer:  
####   
#### ```text  
#### [ ][ ][ ][ ][ ][ ][ ]  
#### ```  
####   
#### Assume that a 1 is written into the middle of the buffer (exact starting location does not matter in a circular buffer):  
####   
#### ```text  
#### [ ][ ][ ][1][ ][ ][ ]  
#### ```  
####   
#### Then assume that two more elements are added — 2 & 3 — which get appended after the 1:  
####   
#### ```text  
#### [ ][ ][ ][1][2][3][ ]  
#### ```  
####   
#### If two elements are then removed from the buffer, the oldest values inside the buffer are removed.  
#### The two elements removed, in this case, are 1 & 2, leaving the buffer with just a 3:  
####   
#### ```text  
#### [ ][ ][ ][ ][ ][3][ ]  
#### ```  
####   
#### If the buffer has 7 elements then it is completely full:  
####   
#### ```text  
#### [5][6][7][8][9][3][4]  
#### ```  
####   
#### When the buffer is full an error will be raised, alerting the client that further writes are blocked until a slot becomes free.  
####   
#### When the buffer is full, the client can opt to overwrite the oldest data with a forced write.  
#### In this case, two more elements — A & B — are added and they overwrite the 3 & 4:  
####   
#### ```text  
#### [5][6][7][8][9][A][B]  
#### ```  
####   
#### 3 & 4 have been replaced by A & B making 5 now the oldest data in the buffer.  
#### Finally, if two elements are removed then what would be returned is 5 & 6 yielding the buffer:  
####   
#### ```text  
#### [ ][ ][7][8][9][A][B]  
#### ```  
####   
#### Because there is space available, if the client again uses overwrite to store C & D then the space where 5 & 6 were stored previously will be used not the location of 7 & 8.  
#### 7 is still the oldest element and the buffer is once again full.  
####   
#### ```text  
#### [C][D][7][8][9][A][B]  
#### ```  
####

    *   `push` throws an exception if the buffer is full.
    *   `push_overwrite` moves the `head` index forward to overwrite the oldest element when the buffer is full, then writes the new item.

    *   `peek` returns the oldest element without removing it.

circular_buffer.h
```
#if !defined(CIRCULAR_BUFFER_H)
#define CIRCULAR_BUFFER_H

#include <stdexcept>
#include <cstddef>

namespace circular_buffer {

template <typename T>
class CircularBuffer {
public:
    CircularBuffer(size_t capacity);
    ~CircularBuffer();

    // Adds an item to the buffer. Throws an error if the buffer is full.
    void push(const T& item);

    // Adds an item to the buffer. If the buffer is full, overwrites the oldest item.
    void push_overwrite(const T& item);

    // Removes and returns the oldest item. Throws an error if the buffer is empty.
    T pop();

    // Returns the oldest item without removing it. Throws an error if the buffer is empty.
    T peek() const;

    // Returns true if the buffer contains no elements.
    bool is_empty() const;

    // Returns true if the buffer contains the maximum number of elements.
    bool is_full() const;

    // Returns the current number of elements in the buffer.
    size_t size() const;

private:
    T* data;
    size_t capacity;
    size_t head;
    size_t tail;
    size_t count;
};

}  // namespace circular_buffer

#endif // CIRCULAR_BUFFER_H

#include "circular_buffer.h"

namespace circular_buffer {

template <typename T>
CircularBuffer<T>::CircularBuffer(size_t capacity) 
    : capacity(capacity), head(0), tail(0), count(0) {
    data = new T[capacity];
}

template <typename T>
CircularBuffer<T>::~CircularBuffer() {
    delete[] data;
}

template <typename T>
void CircularBuffer<T>::push(const T& item) {
    if (is_full()) {
        throw std::runtime_error("CircularBuffer is full");
    }
    data[tail] = item;
    tail = (tail + 1) % capacity;
    count++;
}

template <typename T>
void CircularBuffer<T>::push_overwrite(const T& item) {
    if (is_full()) {
        // Overwrite the oldest element by moving the head index forward
        head = (head + 1) % capacity;
    }
    data[tail] = item;
    tail = (tail + 1) % capacity;
    count++;
}

template <typename T>
T CircularBuffer<T>::pop() {
    if (is_empty()) {
        throw std::runtime_error("CircularBuffer is empty");
    }
    T item = data[head];
    head = (head + 1) % capacity;
    count--;
    return item;
}

template <typename T>
T CircularBuffer<T>::peek() const {
    if (is_empty()) {
        throw std::runtime_error("CircularBuffer is empty");
    }
    return data[head];
}

template <typename T>
bool CircularBuffer<T>::is_empty() const {
    return count == 0;
}

template <typename T>
bool CircularBuffer<T>::is_full() const {
    return count == capacity;
}

template <typename T>
size_t CircularBuffer<T>::size() const {
    return count;
}

}  // namespace circular_buffer
