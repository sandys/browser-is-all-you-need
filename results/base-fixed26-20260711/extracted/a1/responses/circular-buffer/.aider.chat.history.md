#### # Instructions  
####   
#### A circular buffer, cyclic buffer or ring buffer is a data structure that uses a single, fixed-size buffer as if it were connected end-to-end.  
####   
#### A circular buffer first starts empty and of some predefined length.  
#### For example, this is a 7-element buffer:  
####   
#### ```text  
#### [ ][ ][ ][ ][ ][ ][ ]  
#### ```  
####   
#### Assume that a 1 is written into the middle of the buffer (exact starting location does not matter in a circular buffer):  
####   
#### ```text  
#### [ ][ ][ ][1][ ][ ][ ]  
#### ```  
####   
#### Then assume that two more elements are added — 2 & 3 — which get appended after the 1:  
####   
#### ```text  
#### [ ][ ][ ][1][2][3][ ]  
#### ```  
####   
#### If two elements are then removed from the buffer, the oldest values inside the buffer are removed.  
#### The two elements removed, in this case, are 1 & 2, leaving the buffer with just a 3:  
####   
#### ```text  
#### [ ][ ][ ][ ][ ][3][ ]  
#### ```  
####   
#### If the buffer has 7 elements then it is completely full:  
####   
#### ```text  
#### [5][6][7][8][9][3][4]  
#### ```  
####   
#### When the buffer is full an error will be raised, alerting the client that further writes are blocked until a slot becomes free.  
####   
#### When the buffer is full, the client can opt to overwrite the oldest data with a forced write.  
#### In this case, two more elements — A & B — are added and they overwrite the 3 & 4:  
####   
#### ```text  
#### [5][6][7][8][9][A][B]  
#### ```  
####   
#### 3 & 4 have been replaced by A & B making 5 now the oldest data in the buffer.  
#### Finally, if two elements are removed then what would be returned is 5 & 6 yielding the buffer:  
####   
#### ```text  
#### [ ][ ][7][8][9][A][B]  
#### ```  
####   
#### Because there is space available, if the client again uses overwrite to store C & D then the space where 5 & 6 were stored previously will be used not the location of 7 & 8.  
#### 7 is still the oldest element and the buffer is once again full.  
####   
#### ```text  
#### [C][D][7][8][9][A][B]  
#### ```  
####

Based on the instructions provided, I will implement a Circular Buffer that supports standard writes (blocking on full), overwrite writes (overwriting oldest data), and reads (removing oldest data).

I have implemented the following logic:
1.  **Fixed Size**: Uses a `std::vector` initialized with a specific size.
2.  **Indices**: Uses `head` to track the oldest element and `tail` to track the next write position.
3.  **Write**:
    *   If the buffer is full and `overwrite` is false, it returns `false` (error).
    *   If the buffer is full and `overwrite` is true, it writes to the `head` position (overwriting the oldest element) and moves the `head` forward. The `count` remains unchanged.
    *   Otherwise, it writes to `tail` and increments `count`.
4.  **Read**: Removes and returns the element at `head`. Throws an error if empty.
5.  **Empty/Full Checks**: Validated against the current `count`.

#if !defined(CIRCULAR_BUFFER_H)
#define CIRCULAR_BUFFER_H

#include <vector>
#include <stdexcept>

namespace circular_buffer {

class CircularBuffer {
public:
    // Constructor initializes the buffer with a fixed size
    explicit CircularBuffer(size_t size);

    // Writes a value to the buffer.
    // Returns false if the buffer is full and overwrite is false.
    bool write(int value, bool overwrite = false);

    // Reads and removes the oldest value from the buffer.
    // Throws std::runtime_error if the buffer is empty.
    int read();

    // Checks if the buffer is full
    bool is_full() const;

    // Checks if the buffer is empty
    bool is_empty() const;

private:
    std::vector<int> buffer_;
    size_t head_;      // Index of the oldest element
    size_t tail_;      // Index of the next element to write
    size_t capacity_;
    size_t count_;     // Current number of elements in the buffer
};

} // namespace circular_buffer

#endif // CIRCULAR_BUFFER_H

```
#include "circular_buffer.h"

namespace circular_buffer {

CircularBuffer::CircularBuffer(size_t size) 
    : buffer_(size), head_(0), tail_(0), capacity_(size), count_(0) {}

bool CircularBuffer::write(int value, bool overwrite) {
    if (is_full() && !overwrite) {
        return false; // Error: buffer is full
    }

    // Write the value at the tail position
    buffer_[tail_] = value;
    tail_ = (tail_ + 1) % capacity_;

    if (is_full()) {
        // If we are overwriting, the oldest element is effectively removed
        // without increasing the count.
        head_ = (head_ + 1) % capacity_;
    } else {
        // Otherwise, we successfully added a new element
        count_++;
    }

    return true;
}

int CircularBuffer::read() {
    if (is_empty()) {
        throw std::runtime_error("Buffer is empty");
    }

    int value = buffer_[head_];
    head_ = (head_ + 1) % capacity_;
    count_--;

    return value;
}

bool CircularBuffer::is_full() const {
    return count_ == capacity_;
}

bool CircularBuffer::is_empty() const {
    return count_ == 0;
}

} // namespace circular_buffer

    if (is_full() && !overwrite) {

    buffer_[tail_] = value;
