02 · Problem

A valid date overflowed inside the formatter.

A coarse-resolution system-clock time point can represent dates beyond year 2262. fmt narrowed that value through the platform’s default nanosecond clock representation before calendar conversion, producing an invalid date.

Minimal reproduction
using time_point =
    std::chrono::time_point<std::chrono::system_clock,
                            std::chrono::milliseconds>;

time_point value(std::chrono::seconds(32503680000));
auto result = fmt::format("{:%Y-%m-%d}", value);

// Required result: "3000-01-01"

# Fix large-date std::chrono::time_point formatting

## Problem
On Linux, the default system_clock::time_point often uses signed 64-bit
nanoseconds and cannot represent dates after roughly 2262. A coarser
system-clock time point can represent later dates, but fmt narrows it through
the default clock duration and overflows.

using time_point = std::chrono::time_point<std::chrono::system_clock,
                                          std::chrono::milliseconds>;
time_point value(std::chrono::seconds(32503680000));
auto result = fmt::format("{:%Y-%m-%d}", value);

Required result: 3000-01-01.

With FMT_SAFE_DURATION_CAST enabled, an unrepresentable conversion from an
extreme duration to seconds must throw fmt::format_error with the existing
message "cannot format duration" rather than wrap. Ordinary, pre-epoch,
fractional-second, negative-subsecond, local-time, and duration formatting
must remain correct.

Only modify include/fmt/chrono.h. C++11 only. Return Aider SEARCH/REPLACE
blocks and no prose.

## Required implementation

1. Add one duration-conversion wrapper as two namespace-level overloads in the
existing fmt inline namespace, after the safe_duration_cast namespace closes
and before FMT_NOMACRO.

Use mutually exclusive C++11 SFINAE conditions based on whether From::rep and
To::rep are both floating-point or both non-floating-point. For same-category
conversions, use safe_duration_cast when FMT_SAFE_DURATION_CAST is enabled,
throwing format_error("cannot format duration") when its error code is nonzero.
Otherwise use std::chrono::duration_cast. Mixed-category conversions use
ordinary duration_cast because the checked overload is not viable for that
combination.

Do not add a nested fmt or detail namespace around these helpers. Do not use a
runtime trait branch, because both branches would still be instantiated.

2. Replace the system-clock gmtime overload with an overload templated on the
time point Duration. Convert time_since_epoch() directly to seconds through
the wrapper, then call the existing gmtime(std::time_t) with the converted
count. Do not convert through the default system_clock duration.

3. In the system-clock time_point formatter:
- compute the fractional remainder as

  auto subsecs = to_duration<Duration>(
      epoch - to_duration<std::chrono::seconds>(epoch));

- create the one-second correction through the same wrapper;
- preserve the negative-subsecond correction and overflow guard;
- call gmtime(val) from both fractional and whole-second formatter paths.

## Invariants
- The helpers remain in the current fmt inline namespace.
- Both SFINAE overloads exist and are mutually exclusive.
- Checked-cast references remain guarded by FMT_SAFE_DURATION_CAST.
- No default-clock time_point conversion is reintroduced.
- The fractional remainder subtracts converted(epoch), not seconds(1).
- Both formatter paths call gmtime(val).
- Existing unrelated source remains unchanged.
- Emit three exact and applicable Aider SEARCH/REPLACE blocks.
04 · Model solution

Direct conversion, compile-time dispatch, no default-clock narrowing.

The generated patch added a checked conversion boundary, generalized calendar conversion to arbitrary system-clock durations, and routed both formatter paths through it.

1

Dispatch by representation

Two C++11 SFINAE overloads separate checked same-category casts from mixed floating/integral casts.

2

Convert epoch to seconds

The generalized gmtime overload accepts any system-clock duration and passes a seconds count to time_t.

3

Preserve subseconds

The formatter computes its remainder from the full epoch and retains the existing negative-time correction.
