# Harbor DOMDiff Smoke Tasks

This directory contains two Harbor-format browser/SWE tasks copied from the
local SGLang worktree for the `harbor-domdiff-browser-swe` smoke benchmark.

Included tasks:

- `radix-ui__primitives-3548`
- `chakra-ui__chakra-ui-8905`

The task folders contain Harbor metadata, Docker build recipes, instructions,
patches, rubrics, verifier scripts, and `gold_signals.json`. They do not
vendor browser source code or upstream repository clones.
